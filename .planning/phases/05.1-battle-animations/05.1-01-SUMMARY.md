## Decisions Made
- Used `(data[i] ?? 0)` pattern for pixel array access to satisfy TypeScript strict indexed access rules
- `blankSprite()` includes hardcoded base64 fallback for environments where Canvas 2D context is unavailable
- `HP_BAR_WIDTH` exported alongside `formatHpBar` because `AnimationEngine` needs to reconstruct HP bar strings at arbitrary HP percentages during drain animation
- `updateImage()` follows existing adapter convention: throws "Not connected" if bridge is null
