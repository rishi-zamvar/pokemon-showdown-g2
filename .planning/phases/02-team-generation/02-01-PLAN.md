Create `src/battle/TeamGenerator.ts` as a module singleton (same pattern as DataLoader — `export const TeamGenerator = { ... } as const`).

Implementation details:

1. **Imports:**
   - `TeamGenerators` from `@pkmn/randoms`
   - `Dex` from `@pkmn/sim`
   - `Generations, Pokemon as CalcPokemon` from `@smogon/calc`
   - `BattlePokemon` from `../types/battle`

2. **Module-level constant:**
   - `const GEN9 = Generations.get(9);`

3. **buildRandom() method:**
   - Call `TeamGenerators.getTeamGenerator('[Gen 9] Random Battle').getTeam()` to get 6 PokemonSet objects
   - Map each set to a BattlePokemon:
     a. Resolve cosmetic forme: `const simSpecies = Dex.species.get(set.species); const calcSpecies = simSpecies.baseSpecies || set.species;`
     b. Construct CalcPokemon to compute stats: `new CalcPokemon(GEN9, calcSpecies, { level: set.level, ability: set.ability, item: set.item ?? '', nature: set.nature ?? 'Hardy', ivs: set.ivs, evs: set.evs, moves: set.moves, teraType: set.teraType as any })`
     c. Extract `calcPokemon.stats` (has hp, atk, def, spa, spd, spe) into the BattlePokemon.stats field
     d. Return the full BattlePokemon object with all fields mapped
   - Return the array of 6 BattlePokemon

4. **Key edge cases handled:**
   - `set.nature ?? 'Hardy'` — gen9 random sets omit nature
   - `set.item ?? ''` — item should always be present but defensive fallback
   - `set.teraType ?? 'Normal'` — should always be present but defensive fallback
   - `simSpecies.baseSpecies || set.species` — resolves Gastrodon-East -> Gastrodon, leaves non-cosmetic formes unchanged
   - Do NOT validate moves.length === 4 — Ditto legitimately has 1 move (Transform)

5. **Do NOT:**
   - Generate team at import time (PRNG should run lazily at battle start)
   - Post-filter for isNonstandard/battleOnly (@pkmn/randoms handles this internally)
   - Re-install any packages (already installed from Phase 1)
