```typescript
const statStages: StatStages = {

  def: simMon.boosts?.def ?? 0,

  spd: simMon.boosts?.spd ?? 0,
  spe: simMon.boosts?.spe ?? 0,
  accuracy: simMon.boosts?.accuracy ?? 0,
  evasion: simMon.boosts?.evasion ?? 0,
};
```

2. **Revealed ability** — the sim always knows the ability. Read from `simMon.ability` (string, always present for active pokemon). For non-active pokemon on the opponent side, the ability may not be "revealed" to the player yet. Use a simple heuristic: if the pokemon has been active at any point (entered the field), its ability is considered revealed. For now, read `simMon.ability` directly for all pokemon — the Stats Screen (Phase 11) can add visibility logic later.
```typescript
const revealedAbility: string = simMon.ability ?? '';
```

3. **Held item** — read from `simMon.item` (string, empty if consumed). Track consumption via `simMon.item === ''` when `prev.heldItem !== ''` (item was present before but now gone).
```typescript
const heldItem: string = simMon.item ?? '';
const heldItemConsumed: boolean = prev.heldItemConsumed || (prev.heldItem !== '' && heldItem === '');
```
Note: On first deriveSide call, prev.heldItem is '' (from initActivePokemon). The original item comes from the BattlePokemon `item` field set during team generation. So also seed heldItem from `prev.item` (the BattlePokemon.item field) on first call:
```typescript
// Seed from team data on first derive (prev.heldItem is '' from init)
const effectiveItem = heldItem || (prev.heldItem === '' && !prev.heldItemConsumed ? prev.item : prev.heldItem);
```
Actually simpler: @pkmn/sim's `simMon.item` reflects the current item accurately (it's the real source of truth). Just use it directly. The initial item is already on BattlePokemon.item from team gen. So:
```typescript
const heldItem: string = simMon.item ?? '';
const heldItemConsumed: boolean = (simMon.item === '' && prev.item !== '');
```
This checks if the sim says no item but the pokemon originally had one.
