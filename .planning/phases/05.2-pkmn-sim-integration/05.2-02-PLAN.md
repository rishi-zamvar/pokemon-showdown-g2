```typescript
import type { Battle } from '@pkmn/sim';
import type { PlayerAction } from '../types/battleState.js';

export const SimAIOpponent = {
  pickAction(battle: Battle): PlayerAction { ... },
  pickSwitch(battle: Battle): number { ... },
} as const;
```

**pickAction(battle) implementation:**

Read `battle.sides[1].activeRequest` (the opponent/AI side). The request is a typed union — it can be a MoveRequest, SwitchRequest, or WaitRequest.

Decision flow:

1. If `!request || request.wait` — return `{ type: 'ATTACK', moveSlug: 'struggle' }` as a safe fallback (the sim handles Struggle).

2. If `request.forceSwitch` — this means a pokemon fainted and we need to switch. Find the first alive non-active pokemon:
   ```typescript
   const pokemon = request.side.pokemon;
   for (let i = 0; i < pokemon.length; i++) {
     if (i < request.forceSwitch.length) continue; // skip active slots
     if (pokemon[i].condition.endsWith(' fnt')) continue; // skip fainted
     return { type: 'SWITCH', toIndex: i };
   }
   ```
   Fallback: return `{ type: 'SWITCH', toIndex: 1 }`.

3. If `request.active?.[0]` (normal move request):
   - Read `request.active[0].moves` — array of `{ move, id, pp, maxpp, disabled, target }`.
   - Filter to non-disabled moves with `pp > 0`.
   - If no moves available, return `{ type: 'ATTACK', moveSlug: 'struggle' }`.
   - **Random selection:** Pick a random non-disabled move (Math.random). This is the simple random AI approach matching PS's built-in RandomPlayerAI.
   - The `id` field is the lowercase slug (e.g., 'thunderbolt') — this is our `moveSlug`.
   - Return `{ type: 'ATTACK', moveSlug: selectedMove.id }`.

   - **Tera consideration:** Optionally, with a small probability (e.g., 20% when not yet used), pick TERA_ATTACK instead. Check `request.active[0].canTerastallize` — if truthy and `Math.random() < 0.2`, return `{ type: 'TERA_ATTACK', moveSlug: selectedMove.id }`. If `canTerastallize` is not a field on the request, check if the side has already terastallized via `battle.sides[1].pokemon.some(p => !!(p as any).terastallized)`.

**pickSwitch(battle) implementation:**

Used by ScreenController when the AI needs to make a forced switch independently. Same logic as the forceSwitch branch in pickAction:
- Read `battle.sides[1].activeRequest`.
- If `request?.forceSwitch`, find first alive non-active pokemon index.
- Return that index (0-based team index).
- Fallback: return the first non-fainted, non-active index from `battle.sides[1].pokemon`.

**Type handling:**

The `activeRequest` type from @pkmn/sim may not be perfectly typed. Use type narrowing:
```typescript
const request = battle.sides[1]!.activeRequest as any;
```
Then check for `request.forceSwitch`, `request.active`, `request.wait` as properties. This is safer than trying to import the exact ChoiceRequest union types which may not be exported cleanly.

**Anti-patterns to avoid:**
- Do NOT import computeDamage or @smogon/calc — the AI does not need damage estimation; the sim handles all mechanics.
- Do NOT import DataLoader — move data comes from the request object.
- Do NOT mutate the battle object — only read from it.
- Do NOT use BattleStream/stream-based patterns.
