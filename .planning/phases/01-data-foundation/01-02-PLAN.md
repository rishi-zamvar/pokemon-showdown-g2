**1. Create `src/types/pokemon.ts`** with interfaces matching the actual JSON structure:

```typescript
export interface PokemonEntry {
  num: number;
  name: string;
  types: string[];
  baseStats: {
    hp: number; atk: number; def: number;
    spa: number; spd: number; spe: number;
  };
  abilities: Record<string, string>;  // { "0": "Overgrow", "H": "Chlorophyll" }
  heightm: number;
  weightkg: number;
  // Filtering fields
  isNonstandard?: string;  // 'Past' | 'LGPE' | 'Future' | 'Custom' | 'CAP' | null
  battleOnly?: string | string[];  // base species name for forme-change Pokemon
  baseSpecies?: string;
  forme?: string;
  // Optional fields present on some entries
  prevo?: string;
  evos?: string[];
  eggGroups?: string[];
  tier?: string;
}

export interface MoveEntry {
  num: number;
  name: string;
  type: string;
  category: 'Physical' | 'Special' | 'Status';
  basePower: number;
  accuracy: number | true;  // true means "always hits"
  pp: number;
  priority: number;
  target: string;
  flags: Record<string, number>;
  // Optional
  isNonstandard?: string;
  secondary?: unknown;
  desc?: string;
  shortDesc?: string;
}

export interface AbilityEntry {
  num: number;
  name: string;
  rating: number;
  desc?: string;
  shortDesc?: string;
  isNonstandard?: string;
}

export interface ItemEntry {
  num: number;
  name: string;
  desc?: string;
  shortDesc?: string;
  isNonstandard?: string;
  fling?: { basePower: number };
}

// TypeChart: typechart[defenseType].damageTaken[attackType]
// Values: 0 = normal, 1 = immune, 2 = 0.5x, 3 = 2x
export interface TypeChartEntry {
  damageTaken: Record<string, number>;
  HPivs?: Record<string, number>;
  HPdvs?: Record<string, number>;
}

export type TypeChart = Record<string, TypeChartEntry>;
```

Inspect a few entries from the actual pokedex.json and moves.json to confirm field names match. Adjust interface if needed (e.g., check if `baseStats` uses `hp`/`atk`/`def`/`spa`/`spd`/`spe` as keys). The interfaces must match the ACTUAL data, not assumptions.

  <action>
Create `src/data/DataLoader.ts` as a module-level singleton (NOT a class with getInstance). Follow the pattern from 01-RESEARCH.md exactly.

**Structure:**

1. **Static imports** for all five data files (pokedex, moves, abilities, items, typechart). Use plain `import foo from './foo.json'` — Vite 6 handles this natively, and `resolveJsonModule: true` is already in tsconfig.

2. **Type imports** from `../types/pokemon` for PokemonEntry, MoveEntry, AbilityEntry, ItemEntry, TypeChart.

3. **Map construction at module load** — build once, never rebuild:
   - `_pokedex: Map<string, PokemonEntry>` from pokedex.json via `Object.entries()`
   - `_moves: Map<string, MoveEntry>` from moves.json
   - `_abilities: Map<string, AbilityEntry>` from abilities.json
   - `_items: Map<string, ItemEntry>` from items.json
   - `_typechart: TypeChart` (plain object, not Map — keys are type names)

4. **Exported `DataLoader` object** with these methods:
   - `validate(): void` — throws if any data is corrupt. Checks:
     - `_pokedex.size >= 800` (current: 1515)
     - `_moves.size >= 900` (current: 900+)
     - `_abilities.size >= 100` (current: 200+)
     - `_items.size >= 50` (current: 100+)
     - `Object.keys(_typechart).length >= 18` (exactly 18 types)
   - `getPokemon(id: string): PokemonEntry | undefined`
   - `getMove(id: string): MoveEntry | undefined`
   - `getAbility(id: string): AbilityEntry | undefined`
   - `getItem(id: string): ItemEntry | undefined`
   - `getTypechart(): TypeChart`
   - `getAllPokemonIds(): string[]` — returns all keys from _pokedex
   - `getAllMoveIds(): string[]` — returns all keys from _moves
   - `getStandardPokemon(): PokemonEntry[]` — filters `!entry.isNonstandard && !entry.battleOnly` from _pokedex. Should return ~897 entries.

Do NOT add per-match methods yet — that is Plan 03.

**Important:** The JSON keys are lowercase IDs (e.g., "pikachu", "thunderbolt"). All lookup methods accept lowercase IDs. Do NOT normalize — callers must pass lowercase.
