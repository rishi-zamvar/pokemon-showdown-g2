Create `src/battle/DamageCalc.ts` with these exports:

**1. `computeDamage(attacker, defender, moveSlug, isCrit): number`**

Parameters: `attacker: ActivePokemon`, `defender: ActivePokemon`, `moveSlug: string`, `isCrit: boolean`.

Implementation (directly from research Pattern 2):
- Import `{ Generations, Pokemon as CalcPokemon, Move as CalcMove, calculate }` from `@smogon/calc`.
- `const GEN9 = Generations.get(9);` at module level.
- Construct CalcPokemon for attacker: use `attacker.calcSpecies`, level, ability, item (use `''` not undefined if empty), nature, ivs, evs, status (cast as any), curHP set to `attacker.currentHp`.
- CRITICAL: Set `teraType` on attacker ONLY if `attacker.teraActive === true`. Otherwise undefined. This lets @smogon/calc handle Tera STAB correctly.
- CRITICAL: Set `teraType` on defender ONLY if `defender.teraActive === true`. This handles defensive Tera type.
- Construct CalcMove: `new CalcMove(GEN9, moveSlug, { isCrit })`.
- Call `calculate(GEN9, calcAttacker, calcDefender, calcMove)`.
- Extract `result.damage as number[]` — always 16 values in Gen 9 singles.
- Return `rolls[Math.floor(Math.random() * rolls.length)]` for random variance.

**Anti-patterns (from research):**
- Do NOT apply burn halving manually — @smogon/calc handles it when `status: 'brn'` is set on attacker.
- Do NOT compute type effectiveness manually — @smogon/calc handles it.
- Do NOT assume result.damage is a single number — it is always number[] (16 rolls).

**2. `rollCrit(critRatio?: number): boolean`**

From research:
```typescript
const thresholds = [24, 8, 2, 1]; // critRatio 0-3
const threshold = thresholds[Math.min(critRatio ?? 0, 3)];
return Math.floor(Math.random() * threshold) === 0;
```

**3. `doesMoveHit(accuracy: number | true): boolean`**

From research:
```typescript
if (accuracy === true) return true;
return Math.random() * 100 < accuracy;
```

**4. `getMovePP(moveSlug: string): number`**

Look up `DataLoader.getMove(moveSlug.toLowerCase())?.pp ?? 0`. Return the max PP for the move.

**5. `getMoveAccuracy(moveSlug: string): number | true`**

Look up `DataLoader.getMove(moveSlug.toLowerCase())?.accuracy ?? true`. Return accuracy value.

**6. `getMovePriority(moveSlug: string): number`**

Look up `DataLoader.getMove(moveSlug.toLowerCase())?.priority ?? 0`.

**7. `getMoveCritRatio(moveSlug: string): number`**

Look up `(DataLoader.getMove(moveSlug.toLowerCase()) as any)?.critRatio ?? 0`.

Handle Status-category moves: if `DataLoader.getMove(moveSlug)?.category === 'Status'`, `computeDamage` should return 0 (status moves deal no direct damage). This avoids passing non-damaging moves to @smogon/calc which may throw.

  <action>
Update `BattleEngine.ts` to import and use DamageCalc functions. Replace the placeholder 50 HP damage with real damage calculation.

**In the attack resolution path of submitAction():**

1. **PP Check:** Before executing an attack, check PP:
   - Get max PP: `getMovePP(moveSlug)`.
   - Get used PP: `attacker.ppUsed[moveSlug] ?? 0`.
   - If `usedPP >= maxPP`, the move is blocked. Log a `PP_OUT` event. Skip the attack entirely (attacker loses their turn — they chose an invalid move). This follows the requirement "blocks selection at 0."
   - If PP is available, increment ppUsed for that move by 1 (via immutable spread on the ppUsed record).

2. **Accuracy Check:** After PP passes, roll accuracy:
   - `const accuracy = getMoveAccuracy(moveSlug)`.
   - `if (!doesMoveHit(accuracy))` — log a `MISS` event and skip dealing damage.

3. **Crit Roll:**
   - `const critRatio = getMoveCritRatio(moveSlug)`.
   - `const isCrit = rollCrit(critRatio)`.

4. **Damage Calculation:**
   - `const damage = computeDamage(attacker, defender, moveSlug, isCrit)`.
   - Apply damage: `newHp = Math.max(0, defender.currentHp - damage)`.
   - Set `fainted = newHp === 0`.
   - Log DAMAGE event with `{ moveSlug, damage, isCrit, remainingHp: newHp }`.

5. **Faint check after damage** (already in 03-01 skeleton — just ensure it still works with real damage values).

**Immutability:** All ppUsed updates must be immutable: `{ ...pokemon.ppUsed, [moveSlug]: (pokemon.ppUsed[moveSlug] ?? 0) + 1 }`.

**Clean up:** Remove the placeholder "50 HP" damage constant and any TODO comments about replacing it.

After wiring, run the smoke test from 03-01 (or update it) to verify real damage is being dealt. The damage amounts should now vary based on actual Pokemon matchups.
