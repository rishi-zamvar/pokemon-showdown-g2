Exact types to define (from research):

```typescript
export type BattlePhase = 'WAITING_FOR_ACTION' | 'RESOLVING_TURN' | 'WAITING_FOR_SWITCH' | 'BATTLE_OVER';
export type StatusCondition = 'brn' | 'par' | 'psn' | 'tox' | 'slp' | 'frz' | '';

export interface ActivePokemon extends BattlePokemon {
  currentHp: number;
  status: StatusCondition;
  toxicCounter: number;
  sleepTurns: number;
  teraActive: boolean;
  ppUsed: Record<string, number>;
  fainted: boolean;
}

export interface BattleSide {
  team: ActivePokemon[];
  activeIndex: number;
  teraUsed: boolean;
}

export type PlayerAction =
  | { type: 'ATTACK'; moveSlug: string }
  | { type: 'SWITCH'; toIndex: number }
  | { type: 'TERA_ATTACK'; moveSlug: string };

export interface TurnLogEntry {
  kind: 'DAMAGE' | 'MISS' | 'FAINT' | 'STATUS_INFLICT' | 'STATUS_TICK'
       | 'SWITCH' | 'TERA' | 'WIN' | 'LOSS' | 'PP_OUT' | 'PARALYSIS_SKIP' | 'FROZEN' | 'ASLEEP';
  actor: 'player' | 'opponent';
  detail: Record<string, unknown>;
}

export interface TurnResult {
  nextState: BattleState;
  log: TurnLogEntry[];
}

export interface BattleState {
  readonly phase: BattlePhase;
  readonly playerSide: BattleSide;
  readonly opponentSide: BattleSide;
  readonly turnCount: number;
  readonly winner: 'player' | 'opponent' | null;
}
```

Also export a helper function `initActivePokemon(pokemon: BattlePokemon): ActivePokemon` that sets currentHp to stats.hp, status to '', toxicCounter to 0, sleepTurns to 0, teraActive to false, ppUsed to {}, fainted to false.

**TurnResolver.ts** — Export `resolveTurnOrder()`:

```typescript
function resolveTurnOrder(
  playerAction: PlayerAction,
  opponentAction: PlayerAction,
  playerActive: ActivePokemon,
  opponentActive: ActivePokemon,
): ('player' | 'opponent')[]
```

Logic (from research Pattern 3):
1. Switches always resolve before attacks. If both switch, return `['player', 'opponent']`.
2. If one switches and one attacks, switcher goes first.
3. Both attacking: compare move priority via `DataLoader.getMove(moveSlug)?.priority ?? 0`. Higher priority goes first.
4. Same priority: compare `stats.spe`. Higher speed goes first. Important: paralysis does NOT reduce speed in Gen 9.
5. Speed tie: `Math.random() < 0.5` to decide.

Extract moveSlug from ATTACK and TERA_ATTACK action types. SWITCH actions have no moveSlug.

**BattleEngine.ts** — Export module singleton `BattleEngine` with three methods:

1. `startBattle(): BattleState`
   - Call `TeamGenerator.buildRandom()` twice (player + opponent).
   - Map each BattlePokemon through `initActivePokemon()`.
   - Return BattleState with phase `WAITING_FOR_ACTION`, turnCount 0, winner null.

2. `submitAction(state: BattleState, playerAction: PlayerAction, opponentAction: PlayerAction): TurnResult`
   - Validate: state.phase must be `WAITING_FOR_ACTION`. Throw if not.
   - Get turn order from `resolveTurnOrder()`.
   - For each actor in order, execute their action:
     - SWITCH: update activeIndex on that side. Log SWITCH event. Reset toxicCounter to 1 if the switched-in Pokemon has 'tox' status.
     - ATTACK / TERA_ATTACK: For now, use PLACEHOLDER damage of 50 HP (Plan 03-02 will replace with real DamageCalc). Apply damage via immutable spread. Check faint after each attack. If target faints, skip remaining attack from that target (dead Pokemon don't attack). Log DAMAGE event.
     - TERA_ATTACK: Also set `teraActive = true` on the attacker and `teraUsed = true` on the side. Validate that `teraUsed` is false before allowing. Log TERA event before DAMAGE event.
   - After all actions resolved, check for faints:
     - If any active Pokemon fainted and that side has alive teammates: set phase to `WAITING_FOR_SWITCH`.
     - If all 6 on a side fainted: set winner, phase to `BATTLE_OVER`.
     - Otherwise: increment turnCount, set phase to `WAITING_FOR_ACTION`.
   - Return `{ nextState, log }`.

3. `submitSwitch(state: BattleState, side: 'player' | 'opponent', toIndex: number): TurnResult`
   - Validate: state.phase must be `WAITING_FOR_SWITCH`. Throw if not.
   - Validate: target Pokemon must not be fainted.
   - Update activeIndex on the specified side.
   - Reset toxicCounter to 1 if switched-in Pokemon has 'tox' status.
   - Check if the OTHER side also needs a forced switch (both fainted same turn). If so, stay in `WAITING_FOR_SWITCH`.
   - Otherwise check for win condition, then set phase to `WAITING_FOR_ACTION`.
   - Increment turnCount.
   - Return `{ nextState, log }`.

**Immutability rule:** NEVER mutate state directly. Always use spread: `{ ...state, playerSide: { ...state.playerSide, team: newTeam } }`. Create helper functions `updateSideTeam(state, sideKey, updater)` to reduce boilerplate.

**Anti-patterns to avoid:**
- Do NOT import @smogon/calc here — that is Plan 03-02's job.
- Do NOT implement status per-turn effects — that is Plan 03-03's job.
- Do NOT implement accuracy checks — that is Plan 03-02's job.
- The placeholder damage (50 HP) is intentional — it lets us verify the engine skeleton works before wiring real damage.
