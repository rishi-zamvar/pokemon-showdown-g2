  <action>
Create `src/battle/StatusEngine.ts` with these exports:

**1. `applyEndOfTurnStatus(pokemon: ActivePokemon): { newPokemon: ActivePokemon; damage: number; log: TurnLogEntry[] }`**

Apply end-of-turn damage based on status (from research Pattern 4):

| Status | Damage | Other |
|--------|--------|-------|
| `brn` | `Math.max(1, Math.floor(pokemon.stats.hp / 16))` | None (physical halving is in @smogon/calc) |
| `psn` | `Math.max(1, Math.floor(pokemon.stats.hp / 8))` | None |
| `tox` | `Math.max(1, Math.floor((pokemon.stats.hp * pokemon.toxicCounter) / 16))` | Increment toxicCounter by 1 |
| `slp` | 0 | Decrement sleepTurns by 1; if reaches 0, clear status to '' (wake up) |
| `frz` | 0 | No end-of-turn effect (thaw check is at move time) |
| `par` | 0 | No end-of-turn effect |
| `''` | 0 | No status |

Apply damage: `newHp = Math.max(0, pokemon.currentHp - damage)`. Set `fainted = newHp === 0`.
Return the updated pokemon, damage dealt, and log entries (STATUS_TICK for damage, or wake-up notification).

IMPORTANT: Use `Math.max(1, ...)` for all damage — minimum 1 HP per tick.
IMPORTANT: For toxic, increment counter AFTER computing damage (so first tick at counter=1 deals 1/16).

**2. `checkMoveBlock(pokemon: ActivePokemon): { blocked: boolean; newPokemon: ActivePokemon; logEntry: TurnLogEntry | null }`**

Check if a status prevents the Pokemon from moving. Call this BEFORE the attack resolution:

| Status | Check | If blocked |
|--------|-------|-----------|
| `par` | `Math.random() < 0.25` | Return blocked=true, log PARALYSIS_SKIP |
| `slp` | `pokemon.sleepTurns > 0` | Return blocked=true, log ASLEEP. Decrement sleepTurns. If sleepTurns reaches 0, clear status to '' (wake up at start of NEXT turn — this turn is still blocked). |
| `frz` | `Math.random() >= 0.20` (80% stay frozen) | Return blocked=true, log FROZEN. If thaw (20%), clear status to '', return blocked=false. |

For all other statuses (brn, psn, tox, ''): return blocked=false, no log.

IMPORTANT for sleep: Decrement sleepTurns here (at move attempt time), not at end of turn. If sleepTurns was 1, it becomes 0 and status clears — but the Pokemon still can't move THIS turn. They move next turn.

**3. `inflictSleep(pokemon: ActivePokemon): ActivePokemon`**

Set `status: 'slp'` and `sleepTurns: 2 + Math.floor(Math.random() * 3)` (2, 3, or 4 turns).
From research Pitfall 6: sleep duration is rolled at inflict time, not each turn.

**4. `resetToxicOnSwitchIn(pokemon: ActivePokemon): ActivePokemon`**

If pokemon has status 'tox', reset toxicCounter to 1 (not 0 — from research Pitfall 7).
Return unchanged pokemon if no toxic status.

Update BattleEngine.ts to integrate StatusEngine into the turn resolution loop. The final turn flow becomes:

**Updated submitAction() turn resolution order:**

For each actor (in turn order from TurnResolver):

1. **Check if actor's active Pokemon is fainted** — skip if dead (they were KO'd earlier this turn).

2. **Check move block (status):** Call `checkMoveBlock(activeAttacker)`.
   - If blocked: log the block reason, skip to next actor. Update the pokemon state (sleep turns decremented, freeze potentially thawed).
   - If not blocked but status changed (freeze thawed): update pokemon state, continue with attack.

3. **PP check** (already from 03-02).

4. **Accuracy check** (already from 03-02).

5. **Crit roll + damage calc** (already from 03-02).

6. **Apply damage + faint check** (already from 03-01/03-02).

**After both actors have acted (end of turn):**

7. **End-of-turn status effects:** For each side's active Pokemon (if not fainted):
   - Call `applyEndOfTurnStatus(pokemon)`.
   - Apply the returned damage and state changes.
   - Check for faint from status damage (burn/poison/toxic can kill).
   - Log STATUS_TICK events.

8. **Post-status faint check:** If any Pokemon fainted from status damage:
   - Check win condition (all 6 fainted).
   - If not won, set phase to WAITING_FOR_SWITCH.

9. **Normal end of turn:** Increment turnCount, set phase to WAITING_FOR_ACTION.

**Tera integration in attack path:**

For TERA_ATTACK actions:
- Validate `side.teraUsed === false`. If already used, treat as regular ATTACK (log warning but don't crash).
- Set `teraActive = true` on the attacking Pokemon.
- Set `teraUsed = true` on the side.
- Log TERA event.
- Then proceed with normal attack resolution. The `computeDamage()` function already reads `teraActive` to pass `teraType` to @smogon/calc.

**Switch toxic reset:**

When processing SWITCH actions (both voluntary in submitAction and forced in submitSwitch):
- Call `resetToxicOnSwitchIn()` on the switched-in Pokemon.
- This is already partially in 03-01 but ensure it uses the StatusEngine function now.
