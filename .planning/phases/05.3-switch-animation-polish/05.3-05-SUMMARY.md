# Phase 5.3 Plan 05: SWITCH & HEAL Animation Summary

**One-liner:** 3-frame pokeball switch-in with shifted-BMP sprite slide, reverse HP drain for heals, status tick flash

## What Was Done

### Task 1: Add SWITCH and HEAL animation to AnimationEngine

Added three new animation capabilities to AnimationEngine:

**SWITCH animation (sequential, before text):**
- 3-frame pokeball sequence: pokeball circle -> filled white square -> checkbox/materialization
- Sprite slide-in: generates shifted BMP frames using `shiftSpriteBmp()` helper that decodes, shifts pixel content, and re-encodes via `encodeBmp`
- 2 slide frames at 3px offset each (SWITCH_SLIDE_PX * SWITCH_SLIDE_FRAMES)
- Runs BEFORE typewriter text (uses `await` directly, not `tasks.push`)

**HEAL animation (concurrent with text):**
- Reverse HP drain: bar fills from prevState HP to nextState HP
- Uses actual BattleState HP values, not entry.detail
- Same step interpolation as hpDrain but in reverse direction

**STATUS_TICK flash:**
- Sprite hit-flash on status damage ticks (burn, poison, etc.)

### Constants added:
- `ANIM.SWITCH_FRAME_MS: 120` -- hold time per transition frame
- `ANIM.SWITCH_SLIDE_PX: 3` -- pixels shifted per slide frame
- `ANIM.SWITCH_SLIDE_FRAMES: 2` -- number of slide frames
