# Phase 5.3 Plan 03: Format Entry Text Expansion Summary

**One-liner:** Added PS-accurate display text for all 38 TurnLogEntry kinds via lookup tables and expanded switch cases in formatEntry.

## What Was Done

### Task 1: Add stat name lookup and team name helper
Added three lookup tables and one helper function:
- `STAT_NAMES` -- maps stat slugs (atk, def, spa, etc.) to display names matching PS BattleTextParser
- `WEATHER_TEXT` -- maps weather IDs to start/end text strings (rain, sun, sand, hail, snow)
- `TERRAIN_TEXT` -- maps terrain effects to start/end text strings (electric, grassy, misty, psychic)
- `teamLabel()` -- returns "your team" or "the opposing team" for side condition messages

### Task 2: Add all new formatEntry cases
Expanded the switch statement from 13 cases to 38 cases covering every TurnLogEntry kind:

**Updated existing cases:**
- `STATUS_INFLICT` -- per-status PS text (burned, frozen solid, paralyzed, poisoned, badly poisoned, fell asleep)
- `SWITCH` -- player says "Go!" while opponent says "Foe sent out"
- `PARALYSIS_SKIP` / `ASLEEP` -- updated phrasing to match PS exactly

**New case groups:**
- Type effectiveness: SUPER_EFFECTIVE, RESISTED, IMMUNE
- Stat changes: STAT_BOOST (rose/sharply/drastically), STAT_UNBOOST (fell/harshly/severely), STAT_CLEAR
- Volatiles: VOLATILE_START (11 conditions), VOLATILE_END (6 conditions)
- Weather/Terrain: lookup-table-driven with fallbacks
- Side conditions: SIDE_START/SIDE_END for 8 effects each (hazards, screens, tailwind)
- Healing: HEAL with 5 source-specific messages
- Items/Abilities: ITEM_REVEAL, ITEM_CONSUME, ABILITY
- Protection: PROTECT with variant detection
- Multi-hit/Failure: HIT_COUNT, MOVE_FAIL
- Charging: PREPARE with 7 move-specific messages
- Misc: RECHARGE, TRANSFORM, CURE_STATUS, FLINCH_SKIP, RECHARGE_SKIP, ACTIVATE, TEXT
