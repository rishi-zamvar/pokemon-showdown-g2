# Phase 5.3 Plan 04: Volatile Status HUD Display Summary

**One-liner:** Volatile status display in battle HUD via VOLATILE_ABBREVS map, sim adapter extraction, and single-bracket name format with 64-char truncation.

## What Was Done

### Task 1: Add volatiles field to ActivePokemon
- Added `volatiles: string[]` to ActivePokemon interface
- Updated `initActivePokemon` to return `volatiles: []`
- Commit: ef03f0b

### Task 2: Read volatile statuses from sim in SimBattleAdapter
- Added `VOLATILE_ABBREVS` map with 12 volatile conditions (confusion, taunt, encore, disable, leech seed, curse, substitute, focus energy, must recharge, trapped, partially trapped, flinch)
- Extract volatiles from `simMon.volatiles` object keys in `deriveSide`
- Commit: 59c8971

### Task 3: Update battleHudRenderer formatName
- Replaced `formatName` with new version showing tera type, status, and volatiles in single bracket
- Format: `"Label: Name (TeraType | BRN, CNF)"` with overflow truncation at 64 chars
- `formatStatus` now returns empty string (status shown inline)
- Changes included in existing commit chain (05.3-07 fix and 05.3-03 commits built on top)

None -- plan executed exactly as written.
