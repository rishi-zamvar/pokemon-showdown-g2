# Phase 5.3: Switch Animation & Text Polish - Context

**Gathered:** 2026-02-27
**Status:** Ready for planning

<domain>
## Phase Boundary

Switching Pokemon plays a 3-frame pokeball animation sequence, then shows the new Pokemon sprite with a 2-3px slide effect. ALL battle events from @pkmn/sim protocol get proper text display during animation — every single protocol message type. This must be a **perfect simulator** matching Pokemon Showdown's battle flow.

</domain>

<decisions>
## Implementation Decisions

### Switch Animation
- 3-frame sequence: pokeball -> green filled square -> green checkbox square -> pokemon sprite
- Frame speed: No artificial delays — send frames as fast as glasses accept (await each updateImage)
- Sprite slide: New pokemon sprite slides 2-3px left-to-right on entry
- Text during frames: "YOU SENT OUT [POKEMON]" typewriters simultaneously with the 3 frames
- Both sides: Opponent switch also plays full 3-frame animation with "Foe sent out [POKEMON]!"
- Forced switch (faint): Also plays full 3-frame animation after faint flash
- Frame assets: Generated programmatically as BMP (simple shapes — circle, filled square, checkbox)
- resolveSwitch() must animate: Currently skips animation entirely — needs full animation like resolveTurn()

### HUD Status Display
- Format: Single bracket — `Pikachu (Fire | BRN, CNF)` when tera'd with statuses
- Without tera: `Pikachu (BRN, CNF)` — statuses in brackets
- Without status: `Pikachu (Fire)` — just tera type
- Neither: `Pikachu` — no brackets
- Priority order: Tera type first, then non-volatile status, then volatile statuses
- Volatile abbreviations: Short caps like PS — CNF, TAUNT, ENCORE, DISABLE, SEED, CURSE, FLINCH
- Non-volatile abbreviations: BRN, PAR, PSN, TOX, SLP, FRZ (already in code)
- Can show both: One non-volatile + multiple volatiles (e.g., BRN, CNF) — but never two non-volatiles (impossible in Pokemon)
- Overflow: Priority order truncation with `...` — show what fits (tera > non-volatile > volatiles)
- Display limit: 64 chars per line on G2

### Heal Animation
- Reverse HP drain: HP bar fills up progressively (same as damage drain but in reverse)
- Entry hazard damage: Full damage animation (sprite flash + HP drain + text) on switch-in

### Protocol Messages — COMPLETE COVERAGE
Every @pkmn/sim protocol message must have text. This is a **perfect simulator**.

**Already handled (keep/improve):**
- `|move|` — move usage
- `|-damage|` — direct damage + residual (with [from] tag)
- `|-miss|` — miss
- `|faint|` — faint
- `|-status|` — non-volatile status infliction
- `|switch|` / `|drag|` — switching
- `|-terastallize|` — tera
- `|cant|` — paralysis/freeze/sleep skip
- `|-crit|` — critical hit flag
- `|win|` — battle end

**New — Type effectiveness (HIGH priority):**
- `|-supereffective|` -> "It's super effective!" (after damage text, separate entry)
- `|-resisted|` -> "It's not very effective..."
- `|-immune|` -> "It doesn't affect [Pokemon]..."

**New — Stat changes:**
- `|-boost|POKEMON|STAT|AMOUNT` -> "Pikachu's Attack rose!" / "sharply rose!" (+2) / "drastically rose!" (+3)
- `|-unboost|POKEMON|STAT|AMOUNT` -> "Pikachu's Defense fell!" / "harshly fell!" etc.
- `|-setboost|` -> "Stats set to X"
- `|-clearboost|` / `|-clearallboost|` -> "Stats returned to normal!"
- `|-swapboost|` -> "Stat changes were swapped!"
- `|-invertboost|` -> "Stats were inverted!"
- `|-copyboost|` -> "Stat changes were copied!"

**New — Volatile status (start/end):**
- `|-start|POKEMON|confusion` -> "Pikachu became confused!"
- `|-start|POKEMON|leechseed` -> "Pikachu was seeded!"
- `|-start|POKEMON|substitute` -> "Pikachu put up a Substitute!"
- `|-start|POKEMON|taunt` -> "Pikachu fell for the taunt!"
- `|-start|POKEMON|encore` -> "Pikachu got an encore!"
- `|-start|POKEMON|disable` -> "Pikachu's [move] was disabled!"
- `|-start|POKEMON|curse` -> "Pikachu was cursed!"
- `|-start|POKEMON|perish3` -> "Perish count: 3!"
- `|-end|POKEMON|confusion` -> "Pikachu snapped out of confusion!"
- `|-end|POKEMON|substitute` -> "Pikachu's Substitute faded!"
- (all other volatile start/end pairs)
- Confusion self-hit handled through `|-damage|` with `[from] confusion`

**New — Weather:**
- `|-weather|rain` -> "It started to rain!" / "Rain continues to fall." / "The rain stopped."
- `|-weather|sandstorm` -> "A sandstorm kicked up!" / etc.
- `|-weather|sun` -> "The sunlight turned harsh!" / etc.
- `|-weather|hail` / `|-weather|snow` -> "It started to hail!" / "It started to snow!" / etc.
- `|-weather|none` -> weather ended

**New — Terrain:**
- `|-fieldstart|move: Electric Terrain` -> "An electric current runs across the battlefield!"
- `|-fieldend|move: Electric Terrain` -> "The electricity disappeared from the battlefield."
- (psychic, grassy, misty terrain)

**New — Entry hazards:**
- `|-sidestart|p1|Stealth Rock` -> "Pointed stones float in the air around your team!"
- `|-sidestart|p2|Spikes` -> "Spikes were scattered on the ground around the foe!"
- `|-sideend|p1|Stealth Rock` -> "The pointed stones disappeared!"
- Hazard damage on switch-in via `|-damage|...|[from] Stealth Rock` -> full damage animation

**New — Screens:**
- `|-sidestart|p1|Reflect` -> "Reflect raised your team's Defense!"
- `|-sidestart|p2|Light Screen` -> "Light Screen raised the foe's Sp. Def!"
- `|-sideend|` -> "Reflect wore off!" / "Light Screen wore off!"
- Tailwind, Aurora Veil, etc.

**New — Items:**
- `|-item|POKEMON|ITEM` -> "Pikachu is holding Leftovers!"
- `|-enditem|POKEMON|ITEM` -> "Pikachu's Sitrus Berry restored HP!" / "Pikachu consumed its berry!"
- Leftovers healing via `|-heal|...|[from] item: Leftovers`
- Life Orb recoil via `|-damage|...|[from] item: Life Orb`

**New — Abilities:**
- `|-ability|POKEMON|ABILITY` -> "Pikachu's Intimidate!" / "Flash Fire raised power!"
- `|-endability|` -> "Pikachu's ability was suppressed!"
- Ability-triggered effects (Trace, Pressure, Mold Breaker, etc.)

**New — HP Recovery:**
- `|-heal|POKEMON|HP` -> "Pikachu restored HP!" with reverse HP drain animation
- `|-heal|...|[from] move: Recover` -> "Pikachu recovered health!"
- `|-heal|...|[from] item: Leftovers` -> "Pikachu's Leftovers restored a little HP!"
- `|-heal|...|[from] move: Wish` -> "Pikachu's wish came true!"

**New — Protect/Endure:**
- `|-singleturn|POKEMON|Protect` -> "Pikachu protected itself!"
- `|-singleturn|POKEMON|Endure` -> "Pikachu braced itself!"

**New — Multi-hit:**
- `|-hitcount|POKEMON|NUM` -> "Hit 3 times!"

**New — Move failure:**
- `|-fail|POKEMON` -> "But it failed!"

**New — Charging/Recharge:**
- `|-prepare|POKEMON|MOVE` -> "Pikachu is charging power!"
- `|-mustrecharge|POKEMON` -> "Pikachu must recharge!"

**New — Transform:**
- `|-transform|POKEMON|SPECIES` -> "Ditto transformed into Pikachu!"

**New — Future moves:**
- Future Sight / Doom Desire delayed attack text

**New — Destiny Bond / Perish Song:**
- Destiny Bond activation text
- Perish Song countdown text

**New — Status cure:**
- `|-curestatus|POKEMON|STATUS` -> "Pikachu was cured of its burn!"
- Natural Cure on switch, Heal Bell, etc.

**New — Trapped:**
- "Pikachu can't escape!" — Shadow Tag, Arena Trap, Mean Look

**New — Protect/Endure/Misc:**
- `|-activate|` -> Context-dependent activation messages
- `|-hint|` -> Clarification text
