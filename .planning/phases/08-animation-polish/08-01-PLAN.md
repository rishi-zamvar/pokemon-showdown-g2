  <name>Task 1: Wire SpeedConfig into AnimationEngine timing</name>
  <files>src/animation/AnimationEngine.ts, src/config/constants.ts</files>
  <action>
Import SpeedConfig into AnimationEngine. Replace the existing `delay(ms)` helper with a speed-aware version:

1. Add a private `scaledDelay(baseMs: number)` method that calls `this.delay(baseMs * SpeedConfig.multiplier())`. When multiplier is 0 (Instant), resolve immediately (same as cancelled). When multiplier is 2.0 (Slow), delays are 2x longer. When multiplier is 0.5 (Fast), delays are half.

2. Add a private `scaledFrameCount(baseCount: number)` method that returns `Math.max(1, Math.round(baseCount * SpeedConfig.multiplier()))`. For Slow (2.0), this DOUBLES the frame count (more frames = smoother). For Fast (0.5), this HALVES the frame count (fewer frames = snappier). For Instant (0), returns 0.

3. Replace ALL `this.delay(ANIM.*)` calls throughout AnimationEngine with `this.scaledDelay(ANIM.*)`. This covers:
   - typewriterText: CHAR_DELAY_MS, PUNCTUATION_PAUSE_MS
   - spriteFlash: FLASH_FRAME_MS
   - hpDrain: HP_FRAME_MS
   - hpHeal: HP_FRAME_MS
   - switchAnimation: SWITCH_FRAME_MS
   - transformAnimation: SWITCH_FRAME_MS
   - playTurn: ENTRY_PAUSE_MS

4. CRITICAL — Also replace any `this.delay(localVariable)` calls where a local variable holds a delay value. Specifically, `typewriterText` uses `this.delay(pauseMs)` where `pauseMs` is a local variable set from ANIM constants. Replace this with `this.scaledDelay(pauseMs)` so the typewriter punctuation pause also scales with speed. Search for ALL occurrences of `this.delay(` and ensure every single one is replaced with `this.scaledDelay(` — there must be ZERO remaining `this.delay(` calls in the class except for the `scaledDelay` method's own internal call to `this.delay(...)`.

5. Replace hardcoded flash cycle counts with scaled versions:
   - HIT_FLASH_CYCLES: `scaledFrameCount(ANIM.HIT_FLASH_CYCLES)` — Slow gets 4 cycles, Fast gets 1
   - FAINT_FLASH_CYCLES: `scaledFrameCount(ANIM.FAINT_FLASH_CYCLES)` — Slow gets 6, Fast gets 2
   - MAX_HP_STEPS: `scaledFrameCount(ANIM.MAX_HP_STEPS)` — Slow gets 40 steps (smoother drain), Fast gets 10
   - SWITCH_SLIDE_FRAMES: `scaledFrameCount(ANIM.SWITCH_SLIDE_FRAMES)` — Slow gets 4, Fast gets 1

6. Keep the existing `delay(ms)` private method unchanged (still used by `scaledDelay` internally). Keep the cancellation-aware behavior intact.

7. Do NOT change ANIM constants in constants.ts — they remain the Normal (1x) baseline values.

IMPORTANT: When SpeedConfig.isInstant(), scaledDelay resolves immediately and scaledFrameCount returns 0. The animation loops will effectively skip (0 iterations). The typewriter will also skip since delay is 0. This makes Instant mode "free" — animations run but complete instantly.
