  <action>
Create `src/battle/AIOpponent.ts` as a module singleton (matching BattleEngine pattern).

**Imports:**
- `computeDamage`, `getMovePP` from `./DamageCalc.js`
- `DataLoader` from `../data/DataLoader.js`
- Types: `ActivePokemon`, `BattleSide`, `BattleState`, `PlayerAction` from `../types/battleState.js`

**Internal helper: scoreMoves(attacker, defender)**
- Filter moves where `(ppUsed[m] ?? 0) < getMovePP(m)` (has PP remaining)
- Map each move to `{ moveSlug, score: computeDamage(attacker, defender, moveSlug, false) }`
- Sort descending by score
- Return the array

**Internal helper: pickBestSwitch(aiSide, defender)**
- Iterate `aiSide.team`, skip `i === aiSide.activeIndex` and `mon.fainted`
- For each candidate, call `scoreMoves(candidate, defender)` and take `[0]?.score ?? 0`
- Track the candidate with highest max score
- Return the index or null if no valid candidates

**Export: AIOpponent.pickAction(state: BattleState): PlayerAction**

Decision flow (order matters):
1. Extract `aiSide = state.opponentSide`, `aiMon = aiSide.team[aiSide.activeIndex]!`, `playerMon = state.playerSide.team[state.playerSide.activeIndex]!`
2. Score all legal moves: `moveScores = scoreMoves(aiMon, playerMon)`, `bestNoTera = moveScores[0] ?? { moveSlug: aiMon.moves[0]!, score: 0 }`
3. **Tera evaluation** (only if `!aiSide.teraUsed`):
   - Score moves with Tera: `scoreMoves({ ...aiMon, teraActive: true }, playerMon)`
   - If `bestTera.score > 0 && bestTera.score > bestNoTera.score * 1.3` -> return `{ type: 'TERA_ATTACK', moveSlug: bestTera.moveSlug }`
   - CRITICAL: Use spread `{ ...aiMon, teraActive: true }` -- NEVER mutate aiMon directly
4. **Switch evaluation**:
   - Check `hasAliveTeammate = aiSide.team.some((m, i) => i !== aiSide.activeIndex && !m.fainted)`
   - Check if all damaging moves score 0: filter moveScores for moves where `DataLoader.getMove(slug)?.category !== 'Status'`, then check if all remaining have score === 0 OR none exist
   - If all damaging moves score 0 AND hasAliveTeammate -> call `pickBestSwitch(aiSide, playerMon)`
   - If switchIndex !== null -> return `{ type: 'SWITCH', toIndex: switchIndex }`
   - Do NOT switch when the Pokemon only has Status moves (use the status move instead)
5. **Attack**: return `{ type: 'ATTACK', moveSlug: bestNoTera.moveSlug }`

**Key pitfalls to avoid (from RESEARCH.md):**
- Never call `calculate()` directly -- always use `computeDamage()` wrapper
- Never mutate state for Tera eval -- always spread copy
- In `pickBestSwitch`, use the candidate `mon` not the current `aiMon` for scoring
- Use `calcSpecies.toLowerCase()` for any `DataLoader.getPokemon()` calls (cosmetic formes)
- Move slugs from `attacker.moves` are already lowercase -- pass directly to `getMovePP()` and `computeDamage()`
- Guard against empty moveScores (all moves have 0 PP) -- fall back to first move in aiMon.moves
